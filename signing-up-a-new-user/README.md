# ![React Authentication with JWT - tktk Microlesson Name](./assets/hero.png)

**Learning objective:** By the end of this lesson, students will be able to tktk

Set up a lifting stage pattern with a registration form and a top-level App.js state for the user. Upon successful registration, the user should get stored in App's state and the router navigation should send them to the authenticated dashboard for the app.

Start by managing all of this simply within the state of the app, no fetch calls required. Once the plumbing is operational and the pattern has been established, add the fetch call into the mix. Display any errors if the response contains them.
