## Version 1.1 - January 16, 2025

### Release details

This release updates lecture code to use Vite version 6, React Router version 7, and React version 19.

#### Additions

- Added the **Make Authenticated Requests** microlesson. This lesson teaches students how to make authenticated requests to a back-end server with a JWT.

#### Changes

- Update lecture code to use Vite version 6.
- Update lecture code to use React version 19.
- Update lecture code to use React Router version 7.
- Update to use internal template version 2.
- Various code/lecture updates to improve readability and delivery. Code in the lecture should also be more consistent with other React content.
- Aligned error handling code with other React content and with the back-end code.
- Made `useContext()` the core method for managing user state.

#### Removals

None.
